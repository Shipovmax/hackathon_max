# Инструкция для ИИ-ассистента (Codex, Claude Code и других)

Это репозиторий хакатона MAX. Прочитай `CLAUDE.md` целиком — там весь контекст продукта,
правила, факты о платформе MAX и план работ. Этот файл нужен только для маршрутизации.

## Определи, с кем работаешь

Если пользователь представился («Я Толик», «Я Яша», «Я Максим») — прочитай его файл задач
и дальше работай строго по нему:

| Кто | Файл задач | Зона ответственности |
|---|---|---|
| Толик | `docs/tasks/tolik.md` | Доменная логика, REST API, инфраструктура, документация |
| Яша | `docs/tasks/yasha.md` | Чат-бот и планировщик |
| Максим | `docs/tasks/maxim.md` | Мини-приложение (React) |

Если не представился — спроси, кто он, и не начинай писать код, пока не ответит.

## Что делать после того, как узнал имя

1. Прочитай `CLAUDE.md` и `docs/tasks/<имя>.md`.
2. Покажи список задач из файла и спроси, с какой начинать. Если человек говорит «дальше»
   или «следующая» — бери первую невыполненную.
3. Работай **только в своей зоне файлов**. Файлы чужой зоны не трогай, даже если кажется,
   что там нужна мелкая правка: скажи об этом человеку, он передаст владельцу зоны.
4. После задачи прогоняй проверки из файла задач и сообщай, что готово.

## Общие правила

- Общайся по-русски. Код, имена сущностей и коммиты — на английском.
- Рабочий токен бота лежит только в локальном `.env`. Не печатай его, не коммить, не
  вставляй в код и тесты.
- Миграции Django создаёт только Толик. Если понадобилось изменить модели — напиши ему.
- Не реализуй ничего из раздела «Won't have» в `CLAUDE.md`.
- Сомневаешься в поведении платформы MAX — сверяйся с dev.max.ru/docs, а не с памятью.
